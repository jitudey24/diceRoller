# Dice Roller

A simple browser-based dice roller. Users can choose how many dice to roll and trigger a roll to display the results and corresponding dice images.

## Features
- Select the number of dice
- Roll Dice button
- Results display area
- Dice image display area

## Technologies
- HTML5
- CSS3
- JavaScript

## Run Locally
1. Clone this repository.
2. Open `index.html` in your browser.

## Project Purpose
This project practices JavaScript event handling, random number generation, and updating the DOM.
